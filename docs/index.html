2–4. Посадочные места IPC-7351B

Ш — размер площадки вдоль оси компонента (Y по IPC), В — поперёк оси (X по IPC). ±X центра — половина расстояния между центрами площадок. Z — общая длина по наружным краям площадок, G — зазор между внутренними краями.

Сводная таблица по выбранному типу (библиотечные размеры)

* — размер изменён относительно расчётного в бо́льшую сторону, чтобы корпус не выступал за площадку (В ≥ Wmax, Z ≥ Lmax).

Методика расчёта и коэффициенты J (можно править)

Z = Lmin + 2·JT + √(CL² + F² + P²)
G = Smax,RMS − 2·JH − √(CS,RMS² + F² + P²)
X = Wmin + 2·JS + √(CW² + F² + P²)
